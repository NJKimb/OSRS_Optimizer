# Svelte + TypeScript + Vite

Frontend for the OSRS Account Optimizer, built with [Svelte 5](https://svelte.dev) and Vite.

## Scripts

- `npm run dev` - start the dev server on port 5173
- `npm run check` - type-check `.svelte` and `.ts` files with `svelte-check`
- `npm run build` - type-check, then build to `dist/`
- `npm run lint` - run Oxlint

Set `VITE_API_URL` to point the client at the API.
